# Flutter CRUD API Practice

## About the Project
This is a beginner-friendly Flutter practice project created to learn how to work with REST APIs. It focuses on CRUD operations using HTTP requests.

## Concepts Learned
- **Create:** Add new data using POST requests.
- **Read:** Fetch data using GET requests.
- **Update:** Modify existing data using PUT or PATCH requests.
- **Delete:** Remove data using DELETE requests.
- JSON encoding and decoding
- HTTP status codes and API responses
- Asynchronous programming using `async` and `await`
- Error handling in API requests

## Technologies Used
- Flutter
- Dart
- HTTP package
- REST API
- JSONPlaceholder (if used in this project)

## Purpose
The purpose of this project is to practice API integration in Flutter and understand how to send HTTP requests and handle server responses.

## Learning Outcome
Through this project, I gained practical knowledge of REST API integration, CRUD operations, JSON handling, and asynchronous programming in Flutter.
